Tune your RØDE PodMic USB on Linux.

Podtune sets the microphone’s onboard compressor, APHEX effects, and gain. Then it records short voice tests so that you can hear the difference.

Get Podtune on GitHub Install

Follows your desktop

Choose Dark, Light, or Omarchy. Omarchy mode uses the colors of your current theme and updates when you switch. Try it on this page.

Presets you can hear

Nine presets set the compressor, Big Bottom, Aural Exciter, and high-pass filter in one step. A card shows Active while the hardware matches it, and Edited after you change a control.

Natural, Warm podcast, Clear calls, Voice-over, Broadcast, Streaming, Bright, Soft voice, and Singing.

Three scales for tone

Warmth drives APHEX Big Bottom. Presence drives the Aural Exciter. Leveling sets the compressor threshold, ratio, and makeup gain together. Each scale shows the hardware values it sets, so nothing is hidden.

A voice test beside the controls

Check levels shows a live waveform with the target band from −18 to −6 dBFS. Record a take, change a preset, record again, and play both through the microphone’s headphone output.

Each take stores its preset, peak level, and clipped samples. Takes stay on your computer.

Every control in Advanced

Set the compressor against a live transfer curve, tune the APHEX effects, adjust the noise gate and headphones, and save your own presets.

A guide next to every control

Point at an info icon for a one-line summary. Select it to open the guide at that topic. The guide explains what each control does to your voice.

Every write is read back

Podtune sends each change over HID or ALSA, then reads the value back from the microphone. If the values differ, the app shows an error instead of a guess.

Verified on firmware 1.19. Other firmware versions keep the gain and playback controls.

Install on Arch or Omarchy

  1. Clone the repository.

    git clone https://github.com/bjarneo/podtune.git && cd podtune

  2. Build and install the package. The command asks for your sudo password and adds the udev rule for the microphone.

    bin/install

  3. Open Podtune from the app launcher.

To run it without the package, use bin/build, then build/podtune. Podtune needs Qt 6, alsa-lib, and PipeWire.
