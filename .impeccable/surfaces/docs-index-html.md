# Podtune showcase page

Scope: the GitHub Pages landing page at `docs/index.html`. Visitor mode: Persuade.

Audience: Linux and Omarchy users who own a RØDE PodMic USB. Job: see the app work, trust that it controls the real hardware, and install it. Action: open the GitHub repository and run the install commands. Proof: the rendered demo video, app screenshots in all three themes, the verified control list. Constraints: no invented claims, no affiliation with RØDE, the app's own visual world.

## Direction contract

THESIS: The product proves itself in motion. The demo video owns the first viewport at near full width, and the page refuses the headline-over-gradient hero with a grid of icon cards.

OWN-WORLD: The app's instrument surface. Ground #17191c, raised #1d1f23, hairline #3e4043, foreground #f0f1f3, one gold #d0b675 for the primary action and set-point marks. Geist for text, Geist Mono only for measured values and commands. 8 px radii, the Set point mark, tick scales as dividers.

STORY: The visitor watches Podtune tune a PodMic, switches the theme and sees the page follow, reads what each part does through real screenshots, checks the verified control list, copies the install commands, and opens GitHub.

FIRST VIEWPORT: A slim bar with the mark and wordmark left and GitHub right. One row with the headline and the gold primary action. The video below at max 1200 px wide fills most of the height, framed like the app window. On mobile the headline, action, and video stack.

FORM: Video first, number 5 of 7 on the ordered list, chosen by the user from the dealt hand. Seed key 6fc849a0. Signature interaction: the Dark, Light, and Omarchy switch re-themes the whole page and its screenshot, the way the app follows the desktop.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
